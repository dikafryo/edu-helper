## 이번에 수정한 한 가지: PIN 변경 시 금고 보존

기존 pen도우미는 새 PIN 해시만 바꾸고 이전 PIN으로 암호화된 금고를 남길 수 있었다. 이에 따라 다음 로그인에서 복호화 실패가 발생할 수 있었다.

1.2.40: 기존 PIN 설정이 있으면 현재 PIN을 먼저 검증한다. 기존 금고를 해제하고 새 PIN으로 재암호화한 뒤 새 검증 해시와 함께 저장한다. 현재 PIN이 틀리거나 기존 금고를 열지 못하면 변경하지 않는다. 화면에는 현재 PIN 입력란을 추가했고 실패 안내가 상태 갱신에 바로 덮이지 않도록 했다.

실행 검증: check-pin-change.mjs에서 실제 WebCrypto 암복호화 함수를 사용하고 브라우저 저장소만 메모리 객체로 대체했다. 현재 PIN 오류 시 금고 보존, 새 PIN으로 복호화 성공, 이전 PIN으로 복호화 실패를 확인했다. check-settings.mjs의 구문·설정 검사도 통과했다.

검증 한계: Chrome 설정 화면 클릭과 실제 사용자 금고 변경은 실행하지 않았다. 사용자 인증정보는 테스트에 사용하지 않았다. 본 변경은 전체 보안 감사나 복무 자동화 완료를 의미하지 않는다.

다음 과제: 이미 로그인된 나이스 탭 재사용 및 종류별 메뉴 이동을 독립 기능으로 구현하고 실제 화면에서 확인. 안내공문 표 붙여넣기의 실제 기안창 검증도 남아 있다.
