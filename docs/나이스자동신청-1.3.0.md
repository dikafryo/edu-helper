# 나이스 자동 신청 1.3.0

기존 활성 탭의 일반 HTML 입력과 별도로, 로그인된 부산 나이스를 탐색하는 실행 경로를 추가했다. 쌤패스의 앱/컨트롤 식별 방식을 참고해 별도 모듈로 구현했다.

## 구현
- 로그인된 pen.neis.go.kr/jsp/main.jsp의 cpr 및 메뉴 준비 상태 검사.
- 중복 실행 차단 및 대상 탭이 여러 개이면 중단.
- 신청 전 PIN 해제와 루틴 변경 여부 검사.
- 종류별 메뉴·신청 화면, 컨트롤 입력, 값 재확인, 일수/시간 계산 검증.
- 승인요청 이후 개인결재선 이름 일치·구성원 로드·적용 결과 확인.
- 최종 상신 호출 없음. 최근 실행 결과를 세션 저장소에 보관.

## 실행 증거와 제한
check-neis-route.mjs: 실제 실행 함수에 모의 eXbuilder 컨트롤을 제공해 시간외근무 성공 경로와 중단 경로를 실행했다. 최종 상신 컨트롤을 요청하면 테스트가 실패하도록 했다. 설정/구문 검사 28개 JS도 통과했다.

실제 업무 데이터로 신청하거나 승인요청하지 않았다. 메뉴 DOM 이벤트, 콤보 값의 형식, 화면 준비 타이밍은 실환경 검증이 필요하다. 연가/출장 전체 경로의 모의 테스트도 아직 부족하다. 현재 버전을 쌤패스와 동등하게 검증된 것으로 표현하지 않는다.

남은 차이: 자동 인증서 로그인, 다양한 교육청, 최종 자동 상신, 과세특 입력, 네이티브 기안창 지원은 이번 구현 범위가 아니다. 단축키는 기존 채우기 경로를 사용한다.
