# 쌤패스 구조 참고 및 결재 흐름 보완

설치된 Chrome 확장 쌤패스 0.16.3의 options.html, sites.js, neis-request.js, manifest.json을 읽어 구조를 확인했다. 비밀번호나 사용자 저장 데이터는 읽지 않았다. 참고 파일 전체를 복사하지 않고 단계 분리와 확인 방식을 적용했다.

핵심 차이: 쌤패스는 나이스 eXbuilder의 MAIN world 내부 컨트롤로 신청·검증·승인요청·결재선 단계를 수행한다. 기존 pen도우미는 일반 DOM 입력과 고정 링크만 있어 후속 단계가 없었다.

1.2.34에서는 메뉴형 설정창과 현재 화면 기반 단계 도우미를 추가했다. 확인은 모든 프레임을 읽기만 하고, 실행은 유일하게 확인된 프레임에 한정한다. 실제 상신 버튼은 호출하지 않는다. 승인요청은 사용자가 실행 버튼을 누르면 이루어지며 임시저장을 동반할 수 있음을 표시한다.

에듀파인은 쌤패스의 나이스 전용 컨트롤로 해결할 수 없으므로, 로그인된 화면에서 정확한 메뉴/다음 버튼을 탐색하는 별도 방식을 구현했다. 후보가 없거나 여러 개면 중단한다.

검증: 모의 eXbuilder 컨트롤/DOM과 프레임 응답 테스트. 실제 나이스·에듀파인·공문 기안 환경에서 문제 해결을 재현 확인하지 못했다. 네이티브 HWP 기안창은 이 브라우저 방식의 범위 밖이다. 다음 확인은 실제 멈추는 화면의 앱/컨트롤 및 오류 메시지이며, 테스트 통과만으로 세 문제가 모두 해결됐다고 판단하지 않는다.
