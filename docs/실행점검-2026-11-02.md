# 실제 기능 실행 점검

## 현재 상태

연결된 Windows 화면에서 Chrome·나이스·에듀파인·WXSClient 창이 발견되지 않았다. 기존 Chrome 실행 경로로 실행을 시도했으나 파일을 찾지 못했다. 따라서 아래 기능은 실제 실행 통과로 처리하지 않는다.

코드의 check-workflow.mjs는 통과했지만 이는 모의 테스트이며 실제 실행 검증과 구분한다.

## 실행 순서

| 순서 | 기능 | 확인 기준 | 현재 결과 |
| --- | --- | --- | --- |
| 1 | 확장 다시 로드·설정 열기 | 설치 버전 1.2.34, 메뉴 이동, 내용 표시 | 대기 |
| 2 | 시작 안내·권한·단축키 | 실제 구성과 표시 일치 | 대기 |
| 3 | 테마 선택 | 저장 후 팝업 재열기에 반영 | 대기 |
| 4 | 복무 루틴 미리보기 | 날짜·시간·사유 표시, 취소 후 원본 유지 | 대기 |
| 5 | 할 일 검색·필터 | 표시 건수와 목록 일치 | 대기 |
| 6 | 업무포털·에듀파인·나이스 열기 | 로그인 여부와 실제 도착 화면 확인 | 대기 |
| 7 | 결재대기 메뉴 확인 | 로그인된 에듀파인에서 후보 한 개 확인 | 대기 |
| 8 | 나이스 복무 단계 확인 | 현재 신청/결재선 창에 맞는 단계 표시 | 대기 |
| 9 | 기안 다음 단계 확인 | 브라우저/별도 WXSClient 여부와 버튼 확인 | 대기 |

각 항목은 실제 실행 → 화면 결과 확인 → 필요시 수정 → 확장/대상 탭 새로고침 → 동일 동작 재검증 순서로 처리한다. 실제 상신·발송·결재 승인이나 시험 목적의 업무 문서 생성은 하지 않는다. 저장이 필요한 테스트는 별도 테스트 데이터를 식별한 후 진행한다.
