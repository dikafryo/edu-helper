# pen도우미 점검 및 개선 계획

기준일: 2026-11-02. 비교 자료: https://hirame-ki.github.io/pass/
범위: chrome-ext의 기존 1.2.29 소스 및 안내 문서. 실제 로그인된 업무 화면 검증은 미실시.

## 방향

쌤패스는 저장된 복무 루틴, 단계별 안내, 처음 설정 안내가 강점이다.
pen도우미는 기존 공문 초안·과제카드·일정 연결 기능을 유지하면서 설정과 실패 복구를 쉽게 만든다.
두 제품의 우열을 단정하지 않고 실제 업무별 클릭 수와 입력 정확성으로 평가한다.

## 1차 적용 (1.2.30)

- 복무 루틴을 JSON 대신 종류·시간·사유 입력칸으로 추가·수정·삭제한다.
- 저장 전 설정 자료형과 루틴 이름·문자열·URL을 검증한다. 오류 발생 시 저장하지 않는다.
- 루틴의 추가 필드는 유지한다. 빈 루틴 목록도 사용자의 선택으로 유지한다.
- 수신 실패 또는 입력 0건을 성공으로 표시하던 응답을 수정한다.
- 고급 JSON은 접어서 기본 화면의 부담을 줄인다. 버전 안내를 갱신한다.

## 점검 중 확인한 한계

- 루틴 Label이 복무 종류로도 사용된다. 현재는 임의 별칭 대신 실제 복무 종류를 입력해야 한다.
- 루틴 Url은 현재 실행 함수에서 사용되지 않아 편집 화면에 노출하지 않았다. 기존 값은 보존한다.
- 루트 README의 PowerShell 실행 파일은 루트에 없고 백업만 있다. 현행 배포 안내는 chrome-ext/README.md를 기준으로 한다.
- 과거 chrome-guide-notes의 세션 핑 설명은 현재 background.js의 핑 제거 구현과 다르다.
- 인증서 자동 로그인 및 결재선 자동화는 이번 범위에 포함하지 않았다.

## 검증 및 적용

자동 검증: 번들 설정 호환, 잘못된 자료형·빈 이름·비HTTPS 주소 거부, 추가 필드 보존, JavaScript 구문 검사.
실제 브라우저에서 옵션 레이아웃과 입력 연결은 별도 확인이 필요하다.
확장 관리 화면에서 다시 로드한 뒤 업무 탭을 새로고침한다. 옵션에서 루틴 저장 후 팝업을 다시 연다.
로그인·상신·발송 및 실제 업무 데이터 입력은 이번 점검에서 실행하지 않았다.
