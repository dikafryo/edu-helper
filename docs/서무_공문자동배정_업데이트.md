# 서무 공문 자동배정 업데이트 명세

> 대상: 업무포털 문서관리 **접수·배부 권한이 있는 과 서무담당자**  
> 작성 목적: PEN도우미에 없는 권한 기능을, 권한 있는 담당자가 적용할 수 있도록 업데이트 사항만 정리  
> 기준일: 2026-11-01 (KST)  
> 관련 코드: `PenExtras.ps1` 공문접수·과제카드 매칭 (`Match-TaskCards`, `Show-GongmunRecvHelper` 등)  
> 기준 데이터 양식: `upload.xlsx` (단위사업카드) — **본 문서에는 실명·실담당자 미기재**

---

## 1. 목적

과 서무담당자가 **접수대기 공문**을 열었을 때,

1. 제목·본문 키워드를 **PC 로컬에서만** 분석하고  
2. 단위사업카드(엑셀) 기준으로 **담당자 1·2·3순위**를 점수·사유와 함께 제시하며  
3. **1순위 담당자를 배부(처리과·담당) 칸에 미리 채워 두고**  
4. **최종 저장·배부·접수는 서무담당자가 직접 확인 후 수행**

하도록 한다.

기존 PEN도우미 **「공문접수 → 과제카드 Top3」** 흐름을 확장한다.  
과제카드 추천 → **과제카드에 매핑된 담당자 추천·1순위 사전배정**까지 한 화면에서 이어지게 한다.

---

## 2. 사용자·권한

| 구분 | 설명 |
|------|------|
| 주 사용자 | 과 서무담당자 (문서관리 **접수 / 배부** 권한 보유) |
| 비대상 | 일반 담당자, 결재권자만 있는 계정, 접수·배부 메뉴가 없는 계정 |
| 권한 전제 | 업무포털에서 해당 과 문서의 접수대기 열람, 배부(처리담당 지정), 문서관리카드 편집이 가능해야 함 |
| PEN도우미 역할 | 추천·미리채움·학습만 수행. **접수완료 / 배부확정 / 저장 / 상신 / 결재** 버튼은 기본 **클릭하지 않음** |
| 적용 주체 | 본 기능은 서무 권한이 있는 PC·계정에만 설치. 일반 사용자용 PEN도우미에는 타일·메뉴를 노출하지 않거나 「권한 필요」로 비활성 |

## 3. 입력 데이터 (엑셀 양식)

### 3.1 파일

- 권장 파일명: `단위사업카드.xlsx` (배포·테스트용 샘플: 작업함의 `upload.xlsx`)
- 시트명 예: `단위사업카드`
- 1~3행: 제목·안내 문구 (데이터 아님)
- **4행: 헤더**, **5행부터 데이터**

### 3.2 컬럼 스키마 (헤더 행 기준)

| 열 | 헤더명 | 용도 | 비고 |
|----|--------|------|------|
| A | No | 일련번호 | |
| B | 세부사업 | 세부사업명 | 키워드·키 생성에 사용 |
| C | 사업항목(요구서) | 요구서 사업항목 | 키워드 가중치 높음 |
| D | 장표 사업항목명(자동) | 장표 동기화명 | 참고·보조 매칭 |
| E | 단위과제카드(자동) | 과제카드명 (복수 시 쉼표 구분) | 기존 과제카드 매칭과 연결 |
| F | 담당자(자동) | 자동 매핑 담당자 (복수 시 쉼표) | ▶수정이 있으면 덮어씀 |
| G | 매칭 | 일치/불일치 등 | 품질 참고 |
| H | 예산현액 | 숫자 | 배정 로직에 미사용(표시만) |
| I | ▶담당자(수정) | **수동 우선 담당자** | 값 있으면 F보다 우선 |
| J | ▶단위과제카드(수정) | **수동 우선 과제카드** | 값 있으면 E보다 우선 |
| K | ▶장표 사업항목 직접지정 | 장표 직접지정 | 보조 |
| L | 키 | `세부사업\|사업항목` 형태 | 학습·중복키 |

### 3.3 담당자·과제카드 해석 규칙

1. 실사용 담당자 = `▶담당자(수정)`가 비어 있지 않으면 그 값, 아니면 `담당자(자동)`.
2. 실사용 과제카드 = `▶단위과제카드(수정)`가 비어 있지 않으면 그 값, 아니면 `단위과제카드(자동)`.
3. 쉼표(`,`)로 구분된 복수 값은 각각 후보로 분리. 같은 행 안에서는 **앞쪽을 1순위 후보에 가산**.
4. **본 명세·로그·화면 캡처·공유 문서에는 실명을 쓰지 않는다.** 예시만 `담당자A`, `담당자B` 사용.

### 3.4 샘플 행 (실명 없음)

| No | 세부사업 | 사업항목 | 단위과제카드 | 담당자 | ▶수정 |
|----|----------|----------|--------------|--------|-------|
| 1 | 교육과정운영지원 | 창의융합교육 | 과학교육운영및지원, 발명교육운영및지원 | 담당자A, 담당자B | (비움 → 자동 사용) |
| 2 | 교육과정운영지원 | 생태환경교육 | 환경교육 | 담당자C, 담당자D | ▶담당자(수정)=담당자C |

엑셀 업로드 UI는 기존 「단위사업카드 엑셀 적용」 경로를 재사용한다.  
업로드 결과는 PC 로컬 JSON(예: `unit_biz_cards.json`)으로만 저장한다.

## 4. 매칭 알고리즘

기존 `PenExtras.ps1`의 `Match-TaskCards` / `Get-TextTokens` / `Record-TaskCardPick` / `task_card_rules.json` 학습을 **1단계로 재사용**하고, **2단계에서 담당자 순위**를 붙인다.

### 4.1 1단계 — 과제카드(또는 사업항목) 점수

입력: 공문 제목 + 본문 (로컬 문자열만).

| 신호 | 가중치(기본) | 설명 |
|------|-------------|------|
| 과제카드명·사업항목명이 본문에 포함 | +40 | 이름 직접 히트 |
| 카드/행 Keywords·세부사업·사업항목 키워드 부분일치 | +18 | `*키워드*` |
| 토큰 완전일치 (2글자 이상) | +12 | `Get-TextTokens` |
| 사용자·학습 규칙 (`task_card_rules.json`) | +25 (Weight 가변) | 키워드→카드 |
| 과거 선택 이력 가산 | +3/회, 힌트 일치 시 +8 (상한 +30) | `History` |
| 엑셀 `키` 열(`세부\|항목`) 부분일치 | +15 | 단위사업카드 전용 |

Top N(기본 3) 과제카드·사업행을 점수 내림차순으로 남긴다.

### 4.2 2단계 — 과제카드 → 담당자

각 Top 행의 실사용 담당자 목록을 펼친다.

| 신호 | 가중치(기본) | 설명 |
|------|-------------|------|
| 상위 과제/사업 행 점수 상속 | ×1.0 | 1위 행 담당자에게 유리 |
| 같은 행에서 앞쪽 나열 순서 | +5, +3, +1 … | 쉼표 구분 1번째 우대 |
| ▶담당자(수정)으로 지정된 이름 | +20 | 서무가 엑셀로 고정한 값 |
| 동일 담당자가 여러 히트 행에 등장 | 점수 합산 | 중복 등장 가산 |
| 최근 동일 키워드로 실제 배정된 이력 | +10 | 로컬 `assign_history.json` |

담당자별로 합산 후 **1·2·3순위** truncate.  
동점이면: (1) ▶수정 지정자 우선 (2) 최근 배정 횟수 적은 쪽(업무량) (3) 이름 가나다.

### 4.3 부재·업무량 보정 (옵션, 기본 켜짐)

로컬 설정 파일 예: `staff_status.json` (서무 PC에만 존재).

| 필드 예 | 의미 | 보정 |
|---------|------|------|
| `absent` / 연가·출장 기간 | 부재 중 | 해당 기간 점수 ×0 또는 순위 제외, 사유에「부재」표시 |
| `openCount` (미처리 배부 건수) | 업무량 | 건수에 따라 −2 ~ −15 (상한 설정) |
| `prefer` | 서무 수동 선호 | +15 |

부재 데이터는 **외부 서버 전송 없이** 서무가 엑셀·간단 UI로 갱신.  
연동 가능한 경우에도 교육청 PC 안에서만 읽고, 본 명세 범위 밖 API는 강제하지 않는다.

### 4.4 학습

서무가 최종 확인한 담당자(1순위가 아니어도)를 `Record-AssignPick`으로 기록.

- 저장: 로컬 `assign_rules.json` / `assign_history.json` (최대 이력 80~100건 순환)
- 동일 키워드 힌트 → 동일 담당자 **2회 이상**이면 규칙 Weight≈28 자동 추가 (과제카드 `Record-TaskCardPick`과 동일 패턴)
- 학습 데이터·엑셀·이름은 **교육청 PC 밖으로 복사·메일·채팅 금지**

## 5. 화면 (1·2·3순위 카드)

타일명 예: **「서무 배정」** 또는 공문접수 화면 확장 패널.  
테마: 블랙/하늘/핑크/화이트(애플 팔레트). **글자 굵게·여백 최소화**.

### 5.1 상단

- 공문 제목 / 문서번호 (읽기 전용, 포털에서 가져온 값)
- 안내 고정 문구: **「저장·배부·접수는 직접 확인 후 누르세요 (자동 클릭 기본 끔)」**

### 5.2 후보 카드 3장 (급한·점수 높은 순 = 1순위가 맨 위)

각 카드에 표시:

1. 순위 배지: `1순위` `2순위` `3순위`
2. 담당자 표시명 (화면에는 실명 가능, **내보내기·공유 시 마스킹**)
3. 점수 % 또는 원점수
4. 사유 한 줄: 예) `사업항목「생태환경교육」히트, 과제카드「환경교육」, ▶수정 우선`
5. 연결 과제카드명
6. 버튼: `[이 사람으로 미리채움]` / `[일정·할 일만 등록]`(기존 기능 재사용 시)

### 5.3 하단 동작

| 버튼 | 동작 |
|------|------|
| 다시 추천 | 제목·본문·엑셀 재스캔 |
| 엑셀 다시 적용 | 단위사업카드 업로드/갱신 |
| 1순위로 미리채움 | 포털 배부·담당 필드만 채움 (**저장 안 함**) |
| 포털 접수화면 열기 | Chrome으로 접수대기 URL |
| 닫기 | 학습 없이 종료 가능 |

달력 위젯 없음. 일정은 **날짜 + 내용 목록**, 기한 지난·급한 것 상위 (기존 UI 규칙).

## 6. 자동배정 흐름 및 안전장치

```
[접수대기 문서 선택]
        ↓
[제목·본문 로컬 수집]  ← 외부 전송 없음
        ↓
[Match-TaskCards + 단위사업카드 매칭]
        ↓
[담당자 1·2·3 산출 + 부재·업무량 보정]
        ↓
[화면 표시: 1순위 강조]
        ↓
[선택] 「1순위로 미리채움」
        ↓
[포털 UI에 담당/처리 필드 채움만]
        ↓
[서무 최종 확인] → 저장 / 배부 / 접수 클릭은 사람
```

### 안전장치 (필수)

1. **최종 확인은 항상 서무담당자.** 자동으로 접수완료·배부확정하지 않음.
2. **「저장/배부/접수 자동 클릭」옵션은 기본 OFF.** ON은 설정에 이중 확인(체크 + 「자동클릭 허용」문구 입력) 후에만.
3. PEN 전역 규칙과 동일: **결재올림 / 발송 / 상신 / 저장 / 접수 / 확인** 자동 클릭 금지(옵션 OFF 시).
4. 1순위 점수가 임계값(예: 25) 미만이면 미리채움 대신 「후보 없음 — 수동 선택」만 표시.
5. 부재로 제외된 1순위 후보가 있으면 2순위를 제안하고 사유에「1순위 부재 → 2순위 제안」명시.
6. 동일 문서번호로 이미 미리채움한 경우 재실행 시 덮어쓰기 확인.
7. 모든 동작 로그는 로컬만 (`assign_audit.log`), 실명은 필요 시 이니셜·코드로 마스킹 가능 옵션.

## 8. 설치·적용 절차 (권한 있는 서무 PC)

1. PEN도우미 배포 폴더에 본 명세와 함께 업데이트 스크립트 반영  
   - 예: `F:\claude\01 개발 프로그램\pen도우미\`  
   - 코드: `PenExtras.ps1` 확장 모듈 또는 `PenAssign.ps1` 추가 후 `PenHelper.ps1`에서 타일 연결
2. `docs\서무_공문자동배정_업데이트.md` 보관 (본 파일)
3. 단위사업카드 엑셀을 **엑셀 업로드**로 적용 → 로컬 JSON 생성 확인
4. (선택) `staff_status.json`에 부재·업무량 초기값
5. 업무포털 서무 계정으로 로그인 → 접수대기 1건으로 **미리채움만** 시험 (저장·배부 클릭은 수동)
6. 설정에서 「저장/배부 자동 클릭」이 **꺼짐**인지 확인
7. 문제 시 `bak-*` 백업본으로 롤백. 포털 원본 문서 삭제·강제 접수 금지

일반 사용자(접수·배부 권한 없음) PC에는 **설치하지 않거나 타일 숨김**.

- [ ] 1순위 미리채움 시 포털 담당 필드만 변경, **저장/배부/접수 미클릭**
- [ ] 자동클릭 옵션 기본 OFF, ON 시 이중 확인
- [ ] 부재 등록 시 해당 담당자 제외·차순위 제안
- [ ] 서무가 2순위를 고르면 학습 반영, 다음 유사 공문에 가산
- [ ] 임계값 미만 공문은 미리채움 차단
- [ ] 로컬 폴더 외 네트워크 송신 없음(방화벽/프록시 로그 또는 코드 경로 확인)
- [ ] 테마(블랙 기본)에서 글자 가독·여백 과다 없음
- [ ] 권한 없는 계정에서는 타일 비활성 또는 안내만

## 10. 향후 업데이트 목록

1. 단위사업카드 엑셀 ↔ `Match-TaskCards` 키워드 사전 자동 동기화
2. 서무 전용 「배정 대기함」목록: 접수대기 N건 일괄 추천(건별 확인은 유지)
3. 부재·대결자를 복무 타일·출장 일정과 로컬 연동
4. 업무량 보정용 미처리 건수: 포털 배지 숫자 읽기(기존 세션·배지 로직 재사용)
5. 배정 결과 요약 HTML(실명 마스킹) — **사용자 승인 후에만** 과 내부 공유
6. 「저장/배부 자동 클릭」은 장기적으로도 기본 OFF 유지. 필요 시 감사 로그 강화 후 제한적 허용
7. 과제카드 드롭다운 UIA 실패 시 클립보드 붙여넣기 폴백 고도화(기존 공문접수와 동일 계열)
8. 블랙/하늘/핑크/화이트 테마에서 순위 배지 색만 구분(애플 시스템 컬러)
