나에게 맞는 업무 도우미

필요한 설정을 왼쪽에서 선택하세요. 설정은 현재 브라우저에 저장됩니다.

처음 시작하기

  1. 업무포털에 로그인

    아래 인증서 비밀번호를 저장하면 팝업의 바로 열기가 인증서 창까지 진행합니다.

01 · 인증서 비밀번호

업무포털·공직메일 인증서 로그인 창에 자동으로 입력할 비밀번호입니다. 이 브라우저에만 저장되며 외부로 전송하지 않습니다.

외부 서비스

서비스명과 도메인, 로그인 방식을 저장하면 팝업에서 버튼 한 번으로 열고 자동 로그인합니다. 아이디·비밀번호는 이 브라우저에만 저장되며 외부로 전송하지 않습니다.

02 · 자주 쓰는 복무 루틴

시간·사유를 저장해 팝업에서 다시 쓰세요. 첫 루틴은 복무 단축키 대상입니다. 적용 후 날짜와 내용을 확인하고 상신은 직접 해주세요.

결재 진행

업무 탭을 선택한 상태에서 팝업의 결재 단계 이어가기를 사용하세요.

  1. 나이스 복무

    입력 내용 확인 → 복무 → 결재선 → 승인요청 창 열기. 다시 확인하면 개인결재선 창을 열 수 있습니다. 결재선 선택·지정·상신은 직접 진행합니다.

  2. 에듀파인 결재대기

    로그인한 에듀파인 화면에서 결재대기 메뉴를 찾습니다. 직접 링크로 이동되지 않으면 이 메뉴 방식으로 확인하세요.

  3. 공문 기안

    현재 화면의 ‘다음’ 또는 ‘다음 단계’ 버튼을 찾습니다. 후보가 여러 개거나 없으면 임의 클릭하지 않고 안내합니다.

승인요청은 임시저장을 동반할 수 있습니다. 최종 상신·발송·결재 승인은 자동 실행하지 않습니다. 화면 구조가 다르면 직접 진행해야 합니다.
