# pen도우미 Chrome 확장 (MV3 unpacked)

버전 **1.3.2** — 바로 열기가 업무포털 인증서 로그인까지 진행 (실환경 검증 전).

> PIN 잠금 기본 OFF입니다. 설정 → 인증서 비밀번호에서 인증서 비밀번호를 두 번 입력해 저장하면 바로 열기에 사용됩니다. 저장한 비밀번호는 이 브라우저에만 보관합니다.

## 바로 열기 (1.3.2)
1. 설정 → 인증서 비밀번호에서 인증서 비밀번호를 두 번 입력해 저장합니다.
2. 팝업의 업무포털은 `pen.eduptl.kr`을 열고, 로그인 화면이면 인증서 창에 비밀번호를 한 번 넣습니다.
3. K-에듀파인·나이스는 그 로그인 뒤에 업무포털 상단 메뉴로 엽니다. 이미 로그인된 화면은 건너뜁니다.
4. 비밀번호가 틀린 것 같으면 다시 누르지 마세요. 인증서가 잠길 수 있습니다. 인증서가 여러 개이고 저장된 이름이 없으면 창에서 고른 뒤 다시 누릅니다.

버전 1.3.1 — PIN 잠금과 업무포털 로그인 대상을 좁힘.

## 잠금·로그인 점검 (1.3.1)
- PIN은 숫자 4~12자리입니다. 이미 쓰던 4~6자리 PIN은 그대로 풀립니다. 새로 정할 때는 6자리 이상을 권장합니다.
- PIN 5회 오류 제한은 잠금 해제뿐 아니라 금고 저장·삭제·PIN 끄기에도 적용됩니다. 현재 PIN이 틀리면 금고를 지우거나 잠금을 끄지 않습니다.
- 복무 채우기, 결재 단계, 나이스 자동 신청, 업무포털 비밀번호 채우기는 PIN을 등록하고 해제한 뒤에만 실행됩니다. 단축키도 같습니다.
- 비밀번호는 업무포털(eduptl.kr) 화면에서 비밀번호 칸이 하나일 때만 입력합니다. 버튼 글자가 정확히 "로그인"일 때만 누릅니다.
- 위 동작은 확장 화면에서 온 요청만 받습니다.

버전 1.3.0 — 로그인된 부산 나이스의 복무 자동 신청 경로 (실환경 검증 전).

## 신청부터 개인결재선까지 (1.3.0)
1. 부산 나이스 메인에 로그인한 탭을 하나만 엽니다.
2. 설정 → 복무 루틴에서 종류, 시작~종료 시각(예: 18:00~20:00), 사유, 나이스 개인결재선 이름을 입력합니다.
3. 연가는 사유 코드 00~09를 추가합니다. 출장은 출장지·연락처·출장 구분(10/20/30/40)을 추가합니다.
4. PIN 해제 → 팝업의 루틴 선택 → 날짜·시간 확인 → **신청부터 결재선까지**를 누릅니다.
5. 종류별 메뉴/신청 창 → 입력 및 값 재확인 → 승인요청(임시저장 가능) → 개인결재선 지정까지 진행합니다. 마지막 상신은 직접 합니다.
6. 팝업이 닫히면 다시 열어 최근 실행 결과를 확인합니다. 실패 시 열린 창을 확인하세요. 자동 재시도하지 않습니다.

지원 경로: 시간외근무, 연가, 조퇴, 외출, 지각, 병조퇴, 병외출, 병지각, 출장. 단순 병가, 다일 시간외근무, 임의의 별칭은 자동 경로에서 거부합니다. 이미 작성 중인 신청·결재 창이 있으면 중단합니다. 기존 단축키와 일반 채우기 기능은 이 자동 경로와 별개입니다.

검증: `node chrome-ext/check-neis-route.mjs`는 모의 컨트롤로 시간외 신청→결재선 지정, 작성 중 창 보호, 입력 불일치 중단을 실행했습니다. 연가·출장의 전체 경로 및 실제 부산 나이스 UI는 아직 검증하지 않았습니다. 쌤패스와 동등한 실사용 안정성을 보장하지 않습니다.

## PIN 변경 (1.2.40)
설정 → 비밀번호·잠금에서 현재 PIN과 새 PIN을 입력합니다. 기존 금고는 현재 PIN으로 확인한 뒤 새 PIN으로 재암호화합니다. 현재 PIN 오류 시 변경하지 않습니다. 테스트는 `node chrome-ext/check-pin-change.mjs`로 실행합니다.

1.2.39의 안내초안은 아래 원문 칸에 본문과 표를 함께 붙여넣고 변환한 뒤 **본문+표 함께 복사**를 사용합니다. HTML 표가 포함된 붙여넣기가 필요하며, 실제 한글 기안창 붙여넣기는 아직 검증하지 못했습니다.

## 표 그대로 복사 (1.2.38)
1. 도킹의 **표 만들기·복사**를 누릅니다.
2. 아래 입력칸에 엑셀·웹 표를 붙여넣습니다. HTML 표는 자동 변환되며, 탭/마크다운 텍스트는 **입력 → 표**를 누릅니다. 빈 3×3 표도 만들 수 있습니다.
3. 셀을 눌러 편집한 뒤 **표 그대로 복사**를 누릅니다.
4. 공문 본문에서 Ctrl+V로 붙여넣습니다. 일반 **복사** 버튼은 기존 텍스트 결과용입니다.

클립보드에 HTML 표와 일반 텍스트를 함께 기록합니다. HTML 표의 행·열·셀 병합 구조를 유지하고 공문용 기본 테두리를 적용합니다. 원본 글꼴·색상·이미지·중첩 표는 동일 재현 대상이 아닙니다. HTML 붙여넣기를 지원하지 않는 기안기는 텍스트로 들어갈 수 있으며, 실제 한글/WXSClient 호환성은 아직 검증하지 못했습니다. 텍스트 전용 붙여넣기는 사용하지 마세요.

검증: `node chrome-ext/check-table.mjs`.

## 공문 오타확인 (1.2.37)
- 도킹의 **오타확인**을 누르면 아래 검사 입력칸의 본문을 검사합니다. 비어 있으면 연결된 업무 페이지 본문을 읽습니다.
- 한글/WXSClient 본문은 직접 읽지 못할 수 있습니다. 원문을 검사 입력칸에 붙여넣고 다시 누르세요. 이미 입력된 본문은 자동 갱신하지 않습니다.
- 아래 결과창에 줄 번호·의심 표현·예상 번호를 표시합니다. 원문을 수정하거나 전송하지 않습니다.
- `1. / 가. / 1) / 가)` 계층별 누락·중복·역순 및 대표적인 오타/띄어쓰기 규칙을 검사합니다. 상위 번호가 바뀌면 하위 번호를 다시 시작합니다.
- 전체 맞춤법 검사기가 아닙니다. 중간 발췌·독립된 목록·표에서는 정상 내용도 의심 항목으로 표시될 수 있습니다.
- 팝업의 안내공문 탭에서도 원문/본문 입력 후 **오타확인**을 사용할 수 있습니다.
- 검증: `node chrome-ext/check-proofread.mjs`.

## 시작 잠금과 신청 기능 (1.2.35)
- 팝업·도킹을 열면 PIN 설정/잠금 상태를 먼저 확인합니다. PIN 잠금을 등록하지 않았으면 잠금 화면 없이 바로 사용합니다. 잠금을 켠 경우에만 유효한 잠금 해제 세션 동안 다시 묻지 않습니다.
- PIN 5회 오류는 금고 삭제·잠금 해제가 아닌 5분 입력 제한으로 변경했습니다.
- 핀고정으로 발생한 창 포커스 변경을 재처리하지 않도록 차단했습니다. Chrome 창의 OS 항상 위 기능은 아닙니다.
- 출장추출·출장채우기를 출장신청으로 합쳤습니다. 원문 추출 → 확인·수정 → 신청 화면에서 채우기 순서입니다. 임시 내용은 로컬에 보관합니다.
- 복무신청에서 시간외근무·연가·조퇴·외출·지각·병가·병조퇴를 선택합니다. 기존 화면 매칭을 사용하므로 종류별 실제 입력값 확인이 필요합니다.
- 추가 검증: `node chrome-ext/check-start-lock.mjs`. 실제 Chrome 오류 재현 검증은 아직 하지 못했습니다.

## 설정과 결재 단계 (1.2.34)
- 설정은 별도 탭에서 시작 안내·잠금·루틴·결재 진행·화면/단축키·고급·정보/권한으로 나눕니다.
- 업무 탭에서 팝업 → 결재 단계 이어가기 → 흐름 선택 → 단계 실행 버튼을 누릅니다.
- 나이스: 열린 복무 신청의 승인요청 또는 열린 기안문서상신 창의 개인결재선 버튼을 한 단계씩 실행합니다. 승인요청은 임시저장을 동반할 수 있습니다.
- 에듀파인: 로그인된 화면에서 결재대기 메뉴를 찾습니다. 공문 기안은 정확히 ‘다음’ 또는 ‘다음 단계’인 버튼을 찾습니다.
- 여러 프레임 중 대상이 하나일 때만 진행하며 단계/탭이 바뀌면 중지합니다. 개인결재선 선택·지정 및 최종 상신은 직접 합니다.
- 실제 업무 사이트 검증은 미실시입니다. 다른 버튼명이나 네이티브 한글 창은 지원하지 않으므로 화면 확인이 필요합니다.
- 검증: `node chrome-ext/check-workflow.mjs`.

## 추가 개선 (1.2.33)
- 수정 불가 칸과 입력값 반영 실패를 성공 건수에서 제외합니다.
- 복무·출장의 같은 입력칸을 중복 사용하지 않으며 모호한 선택지는 자동 선택하지 않습니다.
- 별도 일정에는 작동하지 않는 할 일 완료·삭제 버튼을 표시하지 않습니다.
- 할 일 삭제 후 연결 일정 유지 여부를 안내하고, 완료·삭제 실패를 표시합니다.
- 검증: `node chrome-ext/check-settings.mjs`, `node chrome-ext/check-input.mjs`.

## 기능 개선 (1.2.32)
- 팝업의 복무 루틴 선택 → 날짜·시간·사유 확인 → 내용 채우기 순서로 실행합니다.
- 이번 실행의 변경은 저장된 루틴에 반영되지 않습니다. 종료일 역전과 유효하지 않은 날짜를 차단합니다.
- 실행 중 버튼 중복 클릭을 막고, 설정에서 루틴이 변경되면 다시 확인하도록 안내합니다.
- 복무 단축키는 기존대로 첫 루틴을 오늘 날짜로 실행합니다. 미리보기는 팝업에서 사용하세요.
- 할 일 제목 검색과 전체·미완료·오늘까지·완료 필터를 제공합니다. 오늘까지는 기한이 지난 미완료도 포함합니다.
- Enter로 할 일을 추가할 수 있습니다. 한글 조합 중 Enter는 추가하지 않으며, 저장 실패 시 입력 내용을 보존합니다.
- 실제 나이스 입력은 기존 화면 탐색 방식을 사용하므로 최종 입력값은 확인해야 합니다.

## 화면 개선
- 바로 열기·복무 루틴을 중심으로 배치하고 업무 도구·색상 선택은 접어서 표시합니다.
- 팝업 위의 설정 및 루틴 편집 링크에서 설정 화면을 엽니다.
- 밝은 테마의 글자색을 수정하고 버튼·입력칸의 키보드 포커스를 강화했습니다.
- 기존 테마 선택은 유지합니다. 새 설치의 기본 테마는 하늘색입니다.

## 복무 루틴 설정
확장 옵션 → **자주 쓰는 복무 루틴**에서 종류·시간·사유를 입력하고 저장합니다.
팝업을 다시 열면 반영됩니다. 첫 루틴은 복무 단축키 대상입니다.
실제 나이스 복무 신청 화면을 연 뒤 실행하고 날짜·내용을 확인하세요. 상신은 직접 합니다.
고급 JSON 설정은 접힌 영역에서 편집하며, 잘못된 자료형은 저장하지 않습니다.

검증: 프로젝트 폴더에서 `node chrome-ext/check-settings.mjs`.

## 설치 / 업데이트
1. `chrome://extensions` → 개발자 모드 ON
2. **압축해제된 확장 프로그램을 로드** → 이 `chrome-ext` 폴더
3. **업데이트 후 반드시 확장 프로그램 새로고침** 클릭
4. 포털/NEIS/에듀파인 탭 새로고침

## 단축키
- 기본: **Alt+Shift+D** 레일 토글 (물리 키 D → 한글 IME에서도 동작)
- 변경: `chrome://extensions/shortcuts`
- 웹한글기안기 등 입력 중에는 페이지 keydown 폴백이 가로채지 않음(편집 필드 패스)

## UI
- 와이드 side panel 없음 → **오른쪽 가장자리 ~52px 레일**
- 접기 탭 / Y축 드래그 / `chrome.storage.local` 유지
## Microsoft Edge (개인용 unpacked, 스토어 등록 없음)
1. 주소창에 `edge://extensions` 입력
2. **개발자 모드** ON
3. **압축을 푼 확장 로드** → 이 `chrome-ext` 폴더 선택
4. 업데이트 후 확장 **다시 로드** + 포털 탭 새로고침
동일 폴더를 Chrome/Edge 모두에서 로드 가능 (MV3, store 불필요).
